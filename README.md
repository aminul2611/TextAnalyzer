# TextAnalyzer

**TextAnalyzer** is a Python-based project developed to analyze text and extract useful information from textual data.

This project was developed as part of **Assignment 1** for the Mathematical Foundations of Computer Scince course at Southwest University of Science and Technology (SWUST),China.

## Features

- Analyze textual data
- Extract useful information from text
- Simple and user-friendly implementation
- Python-based application
- Easy to run and understand

## Technologies Used

- Python
- Html
- Git
- GitHub

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/aminul2611/TextAnalyzer.git
   ```

2. Navigate to the project directory:

   ```bash
   cd TextAnalyzer
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

   If a `requirements.txt` file is not available, install the required packages manually.

## Usage

Run the Python application:

```bash
python main.py
```

Replace `main.py` with the actual Python file name if your project uses a different entry point.
